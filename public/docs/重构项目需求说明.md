## 1. 项目定位与部署

- 纯静态单页应用，无后端；托管 GitHub Pages。
- hash 路由 + 相对 base：产物可原样放任意服务器 / 子路径。**强约束**：改用 HTML5 history 会让嵌套路由下相对资源解析错乱，务必保持 hash。
- 持久化统一前缀 `physics-newton-ring:`，key 全部收敛在 `utils/constants.js`；大型静态资源（opencv.js）放 `public/` 不进打包链路。
- 运行时 fetch（内置文档、Logo 等）必须手动拼 `import.meta.env.BASE_URL`，dev / build 才都对。

## 2. 技术栈与工程约束

- Vue 3 + Vite + Naive UI + UnoCSS + VueUse + lodash-es + OpenCV.js；包管理 pnpm；ESLint + Prettier（格式化由 IDE 自动执行）。
- 不引 Pinia：跨页状态用 `useStorage` / 模块级单例（`useMeasureStore`、`useHistoryStore`、`useDocsStore`）。
- 组件与 API 显式 import，不配自动导入。
- UnoCSS：**禁用 `presetAttributify`**——组件 prop（如 `icon="i-carbon:xxx"`）会被误解析为不存在的图标 utility，产生 Iconify 告警并拖慢 dev CSS 生成；图标类名必须以字符串字面量出现，菜单 / 卡片图标统一写在路由 `meta.icon` 并以 safelist 兜底；改配置后重启 dev + 硬刷新验证。机制与踩坑详情见 `CONTRIBUTING.md`。

## 4. 布局与导航

- PC / 平板：左侧 240px 可折叠侧栏（折叠 64px）；侧栏底部**本站二维码**（按当前 host 生成，折叠时隐藏）。✅
- 移动端：左上角菜单按钮 + 左抽屉，点击菜单项自动关闭。✅
- 顶栏全宽固定：菜单按钮、Logo（`favicon.svg`，不再用图标字体）、水印开关、主题切换；页脚在内容区滚动容器内做 sticky footer。✅
- 路由表为菜单 / 首页入口卡片 / 页面标题与描述的**单一来源**，新页面进路由即全局生效。✅ 首页不再是固定"四象限"，按路由表循环渲染。

## 5. OpenCV 引擎加载（决策记录）

- 引擎 `public/opencv.js`（约 10 MB）原样下发、不进打包。
- **现行决策：业务按需触发**——真正用到 cv 的用户动作（上传 / 重新检测）才 `loadOpenCv()`，配按钮 loading 态。否决路由层预热：进页即让主线程解析巨型 UMD 冻结数秒，而占位态页面根本不用 cv。
- 演进：全局预热 → 异步组件并行 → 路由层预热 → **业务按需**（当前），每次均为解决卡顿 / 加载失败。
- 遗留：wasm 实例化瞬间仍有短暂冻结（要零冻结需评估 Web Worker）；LoadingScreen 遮罩未接线，现以按钮 loading 代替。

## 6. 功能模块现状

- **识别 `/recognition`** ✅：上传（存入前压缩：最长边 1600 px、JPEG 0.85）→ 两步交互（圆心确认可拖图外 → 环人工核对：勾选 / 改编号 / 顺延重排 / 点击或全屏放大补环）→ 表1 / 表2 / `R̄±U` 实时预览 → 写入会话与历史。旧"点击弹框改环"已取舍为 Zoom 模态 + 表格联动；NSteps 取舍为自定义两步流程 UI。
- **像素标定 `/calibration`** ✅：双图上传 → 圆形截取（可选）→ 叠加对齐（手动 / 自动全局 / 检查对齐 PSR 复核 / 闪烁对比）→ 锁定取点多组 → 标定值 4 位有效数字 →「应用到识别」**持久化**（旧版"不持久化"口径作废）。辅助对齐圆环未迁移（见待办）。
- **历史记录 `/history`** ✅：2×2 方格，查看 / 恢复 / 删除 / 清空；上限 20 条 LRU。
- **数据展示 `/data`** ✅：导入结果 JSON 回显（与导出互逆）；支持一键载入当前会话。
- **导出 `/export`** ✅：图片 / JSON / CSV / 表格 Markdown / 网页 HTML 五种（表格与网页视图样式口径待定稿）。
- **公式原理 `/formula`** ✅：等厚干涉 / 逐差法 / 不确定度评定 KaTeX 静态速查。
- **文档中心 `/docs`** ✅：内置 3 篇手册 + 通用 MD 查看器（拖入 md/zip、去重、会话暂存）+ md/doc/png/打印导出。
- **入口软锁** ✅：4 位动态密码（日×2 + 时×2，容差前一小时），2026-09-25 起自动失效。

## 7. 数据与存储约定

- 存储 key、历史上限、图片压缩参数全部收敛 `utils/constants.js`（单一来源）。
- 数据结构以源码为唯一来源，本文不复制字段：历史单条见 `useHistoryStore.js` 头注释；测量会话快照见 `useMeasureStore.js` 头注释（会话不落盘、仅内存跨页传递，留存请走历史 / 导出）；结果 JSON schema 见 `utils/resultIO.js`（导出与导入互逆）。
- 已知风险：海量图片仍可能顶爆 localStorage（约 5 MB）→ 迁移 IndexedDB 评估中（见待办）。

### 历史决策（已定稿，无需再议）

- attributify 踩坑与禁用 → §2；OpenCV 路由预热 → 业务按需 → §5。
